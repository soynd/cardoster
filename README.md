# cardoster

makes smth like teslas rodster logic to any car in roblox (pc only)
main keybinds:
- hold alt to push car up and enable rotation (ROTATION ONLY AVAIBLE WHEN ALT IS HOLDED KEEP IN MIND)
- zero to open ui you can change in settings to another keybind
